name: Glossary
description: Acronyms, terms, and identifiers used in the bookshelf project
type: reference
---

| Term      | Meaning                                                                                                   |
| --------- | --------------------------------------------------------------------------------------------------------- |
| ISBN      | International Standard Book Number — the standard identifier for books (13-digit modern, 10-digit legacy) |
| ASIN      | Amazon Standard Identification Number — Amazon's unique product ID; for books, often matches ISBN-10      |
| bookshelf | The project name; also the core domain concept (a user's collection of books)                             |
